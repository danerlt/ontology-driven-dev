# 本体驱动开发技术分享

面向研发同事的技术分享，共 24 页（含附录）。主线约 20 分钟，AI 对话轻量 harness 深讲可额外安排 6～8 分钟。采用白底蓝色、固定 16:9 画布，内容依据本仓库的 V9 规范与 Python 销售合同应用样例。

## 打开和讲解

直接双击 `index.html` 即可离线演示。所有字体、样式、脚本与讲稿均已内嵌，不需要启动业务系统或配置大模型。

讲稿会占用部分屏幕空间，现场投影时可关闭。源码链接固定到 `source-revision.txt` 中记录的仓库提交；仅查看源码链接需要联网。文字修改自动存入当前浏览器的本地存储，分享修改后的版本时请下载 HTML 文件。

## 建议讲解节奏

- 第 1～4 页，约 4 分钟：问题、业务语义契约与三阶段管线。
- 第 5～8 页，约 5 分钟：七模型分工、聚合边界、行为规则与源码追溯。
- 第 9～13 页，约 6 分钟：同步联动、收款及审批模拟、查询与界面。
- 第 14～16 页及第 22～23 页，约 5 分钟：工程映射、运行时注册表、AI 总览、质量门禁与讨论。
- 第 17～21 页，可选 6～8 分钟：轻量 harness 的代码职责、上下文生命周期、两段式决策循环、工具与 SSE 双通道、真实控制边界。
- 第 24 页：备查阅读路径，不计入主讲时间。

收款示例可依次演示补收 60 万、冲销、取消“阶段足额开票”勾选后再收款、输入 61 万触发额度拒绝。审批示例可依次输入 99 万和 100 万。

第 19 页可以逐步回放一次提问：第一轮返回两个工具，两个工具顺序执行，第二轮决策结束，第三次模型请求再流式生成文字。页面分别计数模型请求和工具执行，支持前进、后退和重置。

## 分析范围

- 业务结论来自仓库规范和 `code-app-example/` 中的实际 YAML、服务、权限、流程与 AI 编排代码。
- 七模型是业务语义约束来源。当前样例由具体代码实现行为；运行时注册表负责装载模型，不代表完整的 YAML 自动编译或热更新平台。
- 主线解释 V9 单体同步方案。单个行为承担一个聚合的职责，样例收款同步写入链共用数据库连接和事务；部分校验发生在事务回调之前。
- 页面交互均为教学模拟，不连接业务后端。收款模拟假设合同只有一张有效开票，处于可结清状态，金额单位为万元。
- AI 只读查询不等于完整的行级权限、硬性结果上限或资源隔离保障；讲稿保留了当前实现与规范目标之间的边界说明。
- AI 深讲经过六组隔离观测：运行真实 `run_chat`、提示词、工具分发与临时数据库查询，只替换模型返回和配置，不调用外部模型，不读取真实 API Key。观测不评价真实模型的选择质量。
- 已确认最近 10 条文本不是 10 轮；原始工具结果不随下一次请求回传；工具 schema 手工维护；5 轮决策可执行超过 5 次工具；最终文字由另一次无工具的流式请求重新生成。

## 修改与验证

内容和逐页讲稿在 `content.py`，AI 深讲在 `harness_content.py`，页面结构、样式与交互在 `src/`。修改后执行：

```pwsh
$env:PYTHONIOENCODING = 'utf-8'
python presentation/build.py
node presentation/verify.mjs
```

构建仅使用 Python 标准库及已保存在 `fonts/` 的字体。若新增汉字需要补充字体子集，可联网运行 `python presentation/fetch_fonts.py` 后重新构建。

校验脚本使用本机 Codex 运行时内置的 Playwright 和 Edge，无需安装项目依赖。它检查离线请求、24 页与讲稿、导航边界、目录、七模型、收款和审批边界、AI 编排回放、编辑持久化、下载、不同屏幕尺寸、打印和脚本异常。逐页截图与校验结果输出到已忽略的 `artifacts/`。

`analyze_harness.py` 还可复核 AI 编排的真实控制逻辑。使用装有 `code-app-example/backend/requirements.txt` 中原有依赖的 Python 执行；脚本自动创建并清理隔离数据库，证据写入 `artifacts/harness-evidence.json`，并核验原业务库未变。

本地 HTTP 预览可执行 `python presentation/preview.py`，访问 `http://127.0.0.1:8765/index.html`。
